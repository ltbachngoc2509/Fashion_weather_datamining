# Fashion Search Trends vs. Weather: Hanoi & Ho Chi Minh City (2013-2026)
Data Mining course project (group of 5). Analyzes how weather relates to fashion search interest on Google Trends in Hanoi and HCMC.

## Key findings
- Hanoi is strongly seasonal; HCMC is stable year-round
- K-Means (k=3): cold-dry / hot-humid-rainy / hot-dry-sunny weeks
- XGBoost Hot Trend classifier: F1 = 0.555 (test set)

## Tools
Python (pandas, scikit-learn, XGBoost), Power BI
